# Funktionsvergleich und Abnahmeplan

Stand 26. November 2026. Jede Zeile benennt einen prüfbaren Produktumfang. Die Referenzen am Zeilenende führen zu Herstellerdokumentation oder zum eigenen Pflichtenheft. Premium-, Coach- und Virtual-Angebote haben unterschiedliche Umfänge. „Teil“ bezeichnet einen konkreten Teilpfad im XC-Projekt, „offen“ eine geplante Funktion. Eine vollständig bestandene Etappe erfordert die Kriterien im [Abnahmebericht](ACCEPTANCE.md).

„App“ umfasst iOS, Android, macOS und Windows als Ziel. „Uhr“ steht für die native watchOS-Begleitung. Plattformangaben in der Tabelle sind Produktziele. Verantwortlich für Messwerte und Freigaben ist das jeweilige Profil.
